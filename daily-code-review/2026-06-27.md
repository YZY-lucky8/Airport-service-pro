### 4.2 弱认证（严重程度：高危）

**`段琼馨/前后端: backend/routes/security.js:985`**
```javascript
if (username === 'admin' && password === 'admin') {
```
- 明文用户名/密码硬编码，`admin/admin` 万能账号
- 无任何哈希、盐值、bcrypt
- 无登录失败锁定

**建议:** 使用 bcrypt 哈希密码存储，实现标准认证流程。

### 4.3 内存型速率限制（严重程度：中危）

`yangziyu/rate-limit: backend/app.js` 中的滑动窗口频率检测使用 `Map` 存储请求时间戳：
- 数据仅存于内存，服务重启后清零
- 无定期清理机制（Map 可能无限增长）
- 分布式部署时无法跨实例共享

**建议:** 改用 Redis 共享速率限制，设置 TTL 自动过期。

### 4.4 BloomFilter 误判风险（严重程度：中低）

- 布隆过滤器有 0.1% 误判率（false positive），即正常 IP 可能被误拦截
- 无白名单豁免机制（被误拦的合法用户无法申诉）
- 黑名单数据硬编码在代码中

**建议:** 添加白名单 bypass 机制，黑名单从数据库动态加载。
